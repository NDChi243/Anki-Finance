HƯỚNG DẪN ĐẶT ẢNH SẢN PHẨM
==============================

Đặt file ảnh vào thư mục này với tên file = id của sản phẩm trong shop_items.json

Ví dụ:
  shop_items.json có  "id": "iphone16"
  → đặt ảnh:          iphone16.jpg  (hoặc .png / .webp / .gif / .svg)

Định dạng hỗ trợ: .jpg / .jpeg / .png / .webp / .gif / .svg
Kích thước khuyến nghị: 400×400px trở lên (hiển thị 120×120px)
Nếu không có ảnh → tự động fallback về emoji icon.

Đã tạo sẵn ảnh SVG placeholder cho TẤT CẢ item trong shop.
Bạn có thể thay thế bằng ảnh thật (jpg/png) cùng tên file để dùng ảnh thật.
